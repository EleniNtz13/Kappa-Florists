ΑΝΘΟΠΩΛΕΙΑ ΚΑΠΠΑ — βελτιωμένος κώδικας

Το ZIP περιλαμβάνει τα HTML/CSS αρχεία που υπήρχαν στο ZIP που παραλήφθηκε. Ο φάκελος εικόνων δεν είχε συμπεριληφθεί στο αρχικό ZIP, επομένως δεν περιλαμβάνεται ούτε εδώ.

ΣΗΜΑΝΤΙΚΟ: Για να μη σπάσουν οι εικόνες, κράτησε τον υπάρχοντα φάκελο images/ του site όπως είναι και ανέβασε τα αρχεία HTML/CSS μαζί του, διατηρώντας την ίδια δομή φακέλων.

Έγιναν ήπιες αλλαγές: προσθήκη loading=lazy και decoding=async σε εικόνες εκτός των hero sections, καθώς και γενικοί κανόνες CSS για responsive εικόνες και μικρές οθόνες. Οι διαδρομές src των εικόνων δεν τροποποιήθηκαν. Δεν ενεργοποιήθηκε αυτόματα το Netlify Image CDN, επειδή χρειάζεται δοκιμή στο δημοσιευμένο site πριν αλλάξουν οι διαδρομές.
